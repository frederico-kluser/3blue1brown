GPU Detection (_detect_gpu_renderer)

def _detect_gpu_renderer() -> bool:
    # 1) GPU hardware presente? (Linux: nvidia-smi, glxinfo)
    gpu_hardware = False
    if sys.platform.startswith("linux"):
        try: nvidia-smi -L → exit 0 → gpu_hardware = True
        try: glxinfo -B com "opengl" → gpu_hardware = True
    if not gpu_hardware:
        return False  # sem GPU → Cairo
    # 2) Manim CLI aceita --renderer=opengl?
    try: manim render --renderer=opengl --help → True
    return False

Decisões de design

  1. Probes: hardware primeiro, flag CLI depois — a revisão adversarial encontrou que o probe do CLI sempre retorna True em Manim ≥ 0.19, tornando os checks de GPU código morto. Corrigido: agora só verifica o flag do CLI se hardware GPU foi detectado primeiro.
  2. Fallback também cobre timeout — se o render OpenGL travar (comum em headless sem contexto GL), o timeout dispara success=False e o fallback Cairo é acionado. Pior caso: 2× timeout, mas só no caminho de fallback.
  3. Cairo NÃO recebe flag — Cairo é o default do Manim; adicionar --renderer=cairo seria redundante e poderia quebrar em versões antigas.
  4. Valor inválido → "auto" — se MANIM_RENDERER for um valor não reconhecido, comporta-se como "auto" em vez de quebrar.
  5. Sem limpeza de media_dir entre tentativas — find_video ordena por mtime, então o output do Cairo (mais novo) sempre vence sobre qualquer artefato do OpenGL.

Como usar

# Forçar GPU (OpenGL)
MANIM_RENDERER=opengl

# Forçar CPU (Cairo — comportamento antigo)
MANIM_RENDERER=cairo

# Auto-detectar (default) — GPU se disponível, Cairo se não
MANIM_RENDERER=auto

# Desabilitar fallback (OpenGL falha → erro, sem retry)
MANIM_RENDERER_FALLBACK=false
